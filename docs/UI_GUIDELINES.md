# UI 文案与信息层级规范

> 与 [`产品规则定稿表.md`](../产品规则定稿表.md) §0、[`冒险世界规则.md`](../冒险世界规则.md) §13.1 对齐。

## 1. 用语

| 使用 | 避免 |
|------|------|
| 冒险、继续冒险、冒险地图 | 探险（状态标签用「冒险中」） |
| 世界进度 | 探索进度（与「探索发现」混淆） |
| 探索发现 | 把宝箱叫「探险奖励」 |
| 伙伴等级 | 与「冒险等级」并列大字 |
| 冒险称号 | 首页主标题区展示主人 Lv |

## 2. 首页信息层级（V1）

1. **宠物卡**：伙伴名字 + **伙伴等级** + 三维状态（主情感入口）
2. **冒险 Banner**（`deriveHomeAdventureBanner`）：当前区域名、当前关卡/在读章节、本区进度 %、世界进度 %、已解锁区域数/6 +「继续冒险」
3. **用户头**：单行布局——左头像+冒险等级角标；中行昵称+称号+**金币**；次行世界进度+连续天数（7 点）；**不**展示精神/体力条（宠物三维见宠物卡）
4. **书架统计卡**：大数字为冒险家等级；红圈区域为 **冒险进度**（主人经验 0/100），**不是**用户体力；无 ⚡ 体力条
5. **已废弃**：`users.energy` /「用户体力」不在产品规则中，UI 不再展示
4. **每日任务**：读/闯、照料、领取（PK 在任务中可选，非第三屏大字）

主人**冒险称号**（青铜冒险家等）仅在 **个人页** [`adventurer-hero`](../components/profile/adventurer-hero.tsx) 展示。

## 3. 冒险地图页「冒险进度」四格

| 格子 | 数据 | 含义 |
|------|------|------|
| 世界进度 | `worldProgress` | 全图关卡 % |
| 收集星星 | `totalStars` | 挑战累计星星 |
| 冒险等级 | `users.level` | 主人等级（次要） |
| 连续冒险 | `daily_streak` | 连续活跃天数 |

数据拉取统一使用 [`lib/adventure/adventure-dashboard-client.ts`](../lib/adventure/adventure-dashboard-client.ts) 的 `fetchAdventureDashboard()`。

## 4. 经验文案

结算提示区分：

- **伙伴 +N 经验** → `pet_exp`
- **冒险进度 +N** → 主人经验（勿与伙伴经验混称「经验」）
