# V2 上线验收清单（对齐产品规则定稿表）

## 1. 商城与背包
- [ ] 打开 `宠物 -> 商城`，显示积分（`users.coins`）与商品列表。
- [ ] 购买后积分减少、库存增加。
- [ ] 积分不足时购买被拦截。
- [ ] 宠物死亡时无法购买。

## 2. 互动（自选 SKU）
- [ ] 无对应类目道具时提示先购买。
- [ ] 同类目仅 1 种道具时直接消耗。
- [ ] 同类目多种道具时弹出仓库选择器。
- [ ] 死亡时无法互动。

## 3. 三维状态
- [ ] 显示 **饱食度** / 精神 / 亲密（非「饥饿值」文案）。
- [ ] 初始或重新领养后三维约为 **80**。
- [ ] 每日首次进首页/宠物页：饱食 **-20**、亲密 **-10**（仅一次/日）。
- [ ] 饱食度 &lt; 50 心情为「饥饿」；亲密 &lt; 50「无聊」；精神 &lt; 50「犯困」。
- [ ] 饱食度 ≤ 0：死亡弹窗 + Chip「离世」。

## 4. 对战门槛与消耗
- [ ] 饱食 &lt; 20 / 精神 &lt; 10 / 亲密 &lt; 10 / 死亡时无法开战。
- [ ] 结算后饱食 **-10**、精神 **-10**。
- [ ] 胜场 **+12 coins** 写入用户账户。

## 5. 等级（方案 A）
- [ ] 进度条为「本级 x%」，非固定 100 经验条。
- [ ] 阶段：1–10 幼崽，11–25 成年，26–50 壮年。
- [ ] 阅读/任务/对战后 `pet_exp` 累计，等级与 `pet_level` 一致。

## 6. 重新领养
- [ ] 死亡弹窗 → 重新领养 → 重选种/名 → 三维 80、Lv.1、背包清空。

## 7. 跨页一致性
- [ ] 商城购买后 `/battle` 状态一致。
- [ ] 刷新后服务端数据与 UI 一致。

## 8. 冒险世界与宠物整合（V1）

- [ ] 阅读章节挑战后饱食/精神**不变**（仅 PK 扣状态）。
- [ ] 首页宠物卡展示**伙伴等级**；用户头展示**世界进度 %**（非「探索进度」）。
- [ ] 冒险地图页「冒险进度」四格接真实数据（世界进度、星星、冒险等级、连续天）。
- [ ] 执行迁移 `20260530190000_user_daily_streak.sql`（或 fix-all-v2 第四节）后，连续天数随登录/挑战/领任务变化。
- [ ] 执行迁移 `20260530200000_treasures.sql` 后，书架「神秘宝藏」进度随星星/活跃/阅读变化，达标自动「已获得」。
- [ ] 新用户每日任务 seed **不含**「知识问答」（`V1_FEATURES.dailyTaskQuestion`）。
- [ ] 冒险页底部探索奖励区块 V1 关闭或显示「后续开放」提示。
- [ ] 文案统一：冒险 / 世界进度 / 探索发现（见 [`UI_GUIDELINES.md`](./UI_GUIDELINES.md)）。

详细部署步骤见 [`DEPLOYMENT.md`](./DEPLOYMENT.md)。
